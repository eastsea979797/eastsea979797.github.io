    • 기존 전·후처리 파이프라인 및 입출력 형식을 유지하여 호환성을 확보하고 추론 레이어의 성능만 극대화

개요

Ollama(로컬 LLM) + ChromaDB(RAG) + Sentence Transformers(임베딩) + Gradio(UI) 구조로, 로컬에서 실행 가능한 소설 생성 시스템입니다.

Novel Maker 설명

  • LLM: Ollama(로컬), Gemma 3 4B, REST API(스트리밍), temperature 0.6, top_p 0.9, top_k 40, repeat_penalty 1.15
  • RAG: ChromaDB(PersistentClient), sentence-transformers/all-MiniLM-L6-v2(384차원), top_k 4, 컨텍스트 1800자
  • 텍스트 분할: 문단 우선, 청크 900자, 오버랩 150자
  • UI: Gradio(스트리밍 출력, 챕터/요약 생성·저장)
  • 라이브러리: gradio, chromadb, sentence-transformers, python-dotenv (Ollama 연동)
  • 아키텍처: KB 문서 RAG 파이프라인(분할→임베딩→ChromaDB→검색→LLM), 이전 화 요약을 다음 화 컨텍스트로 활용
  • 데이터: data/kb(KB 문서), data/chapters(챕터), data/summaries(요약), vectordb(ChromaDB)
  • 설정: 청크 400~900자, 오버랩 50~150자, 목표 3000자, 대화 비율 30%

개요

인구통계·사회경제 데이터를 입력받아 피임 방법 선택(미사용 / 장기 / 단기) 을 3-class 분류로 예측하는 딥러닝 프로젝트입니다.

설명

  • 기술 스택: Python, TensorFlow/Keras, NumPy, Pandas, SciPy, scikit-learn, imbalanced-learn, Matplotlib, Jupyter, Streamlit
  • 사용 모델:
    A One-hot + MLP
    B Embedding + MLP (시연 기본)
    C Wide & Deep (Wide: One-hot, Deep: Embedding, 로짓 합산 후 Softmax)
  • 문제: 클래스 불균형 → 클래스 가중치 + (선택) 오버샘플링(sample_from_datasets).
  • 해결: 과적합/학습 안정성 → EarlyStopping, ReduceLROnPlateau, ModelCheckpoint, L2, Dropout.
  • 운영 시 오판 위험 → 확신 임계값(τ) 도입, “최대 확률 < τ이면 보류” (발표/보고서·확신임계값 설명.txt 반영).
